# 작업 폴더 README.md 형식

```markdown
# <PRD 제목> — 엔지니어 설계

| 항목                 | 값                                           |
| -------------------- | -------------------------------------------- |
| PRD                  | [<제목>](<Notion URL>)                       |
| PRD 최종 수정        | <page_last_edited_at> (마지막으로 읽은 시점) |
| 기준 브랜치 · 리비전 | <브랜치> · `<short sha>`                     |
| 상위 이슈            | #<n> 또는 없음                               |
| 공수 단위            | <wbs 에서 정함>                              |

## 단계 상태

| 단계       | 상태                        | 날짜 |
| ---------- | --------------------------- | ---- |
| understand | 미실행 / 완료 / 재실행 필요 |      |
| verify     |                             |      |
| design     |                             |      |
| diagram    |                             |      |
| wbs        |                             |      |
| publish    |                             |      |

## 설계 문서

| 파일           | 다루는 PRD 절 | 상태                 | Notion |
| -------------- | ------------- | -------------------- | ------ |
| `02-<주제>.md` | §5.2, §5.3    | 초안 / 확정 / 게시됨 | <URL>  |

## 참고한 기존 설계 문서

- `<경로>` — 참고만. 수정하지 않음

## 결정 기록

- <날짜> <문서>§<절> — <결정 한 줄> (PRD 와 다름 / 기존 설계와 다름 표시)
```

## 규칙

- 문서-PRD 절 대응표는 diff 가 영향 범위를 찾는 유일한 근거다. design 단계에서 반드시 채운다
- 결정 기록은 한 줄. 상세는 설계 문서에
