# Content Review — 콘텐츠 품질 검증

Compose/Revise 완료 후, 파일 쓰기 **직전에** 초고를 검증한다.

> Edit 모드는 이미 A/B/C 수정안 → 사용자 승인 흐름이므로 이 리뷰를 **skip**.

---

## Step 1: 리뷰 에이전트 병렬 호출

다음 3개 Agent tool 호출을 **동시에** 실행:

### Agent A: 구조/논리 검토

```
당신은 글 구조 리뷰어입니다.

초고:
[초고 전문]

Brainstorm artifact:
[brainstorm 의 핵심 메시지, 범위, 구조 개요]

다음 관점에서 검토하세요:
1. 핵심 메시지 전달력 — 독자가 1가지 takeaway를 가져갈 수 있는가
2. 논리 흐름 — 도입→전개→결론이 자연스럽게 연결되는가. 논리적 비약이 있는가
3. 범위 준수 — brainstorm에서 정한 포함/제외 경계를 지키는가
4. 도입부 훅 — 첫 2-3문장이 독자의 관심을 끄는가

발견한 이슈를 아래 형식으로 반환:
- [severity: critical/major/minor] <이슈 설명>
  위치: <해당 섹션 또는 문단>
  제안: <구체적 개선 방향>
```

### Agent B: 필체 일관성 검토

```
당신은 필체 일관성 리뷰어입니다.

초고:
[초고 전문]

필체 프로파일:
[style-profile.md 전문]

프로젝트 스타일:
[write-style.md 전문 또는 "__NO_PROJECT_STYLE__"]

다음 관점에서 검토하세요:
1. 리듬 패턴 — 프로파일의 문장 길이/구조 패턴과 초고가 일치하는가
2. 어조 일관성 — 프로파일의 톤(격식/비격식, 직설/완곡)이 유지되는가
3. 금지 표현 — 프로파일/프로젝트 Don'ts에 해당하는 표현이 있는가
4. 용어 일관성 — 같은 개념에 다른 용어를 혼용하고 있지 않은가

발견한 이슈를 아래 형식으로 반환:
- [severity: critical/major/minor] <이슈 설명>
  위치: <해당 문장 또는 표현>
  프로파일 근거: <어떤 규칙과 충돌하는가>
  제안: <수정 방향>
```

### Agent C: 교정 (맞춤법/문법)

```
당신은 교정 리뷰어입니다.

초고:
[초고 전문]

언어: [ko/en]

다음을 검토하세요:
1. 오탈자, 맞춤법 오류
2. 문법 오류 (조사, 어미, 시제 불일치)
3. 띄어쓰기 오류
4. 기술 용어 표기 불일치 (예: "JavaScript" vs "자바스크립트" 혼용)

발견한 이슈를 아래 형식으로 반환:
- [severity: major/minor] <이슈 설명>
  위치: "<원문 표현>"
  수정: "<올바른 표현>"
```

## Step 2: 결과 종합

```
## Content Review

### 구조/논리
- [severity] 이슈 N건

### 필체 일관성
- [severity] 이슈 N건

### 교정
- [severity] 이슈 N건

### 종합 판정: PASS / NEEDS REVISION
```

| 판정           | 조건                                  |
| :------------- | :------------------------------------ |
| PASS           | critical 0건, major 2건 이하          |
| NEEDS REVISION | critical 1건 이상 또는 major 3건 이상 |

## Step 3: 이슈 처리

### PASS (major/minor만 존재)

이슈를 요약 테이블로 한 번에 제시하고 AskUserQuestion:

- **일괄 반영 (⭐ 추천)** — 모든 major/minor 자동 수정
- **선별 반영** — 이슈별로 반영/무시 선택
- **무시하고 진행** — 수정 없이 파일 쓰기

### NEEDS REVISION

critical 이슈를 각각 제시하고 수정 후 **Agent A만 재실행** (최대 2회).
2회 후에도 critical 잔존 시 사용자에게 판단 위임.

## Agent 실패 처리

개별 agent 실패 시:

1. 실패한 agent를 결과에 `⚠️ 실패 (사유)`로 표시
2. 나머지 agent 결과만으로 종합 판정
3. 실패한 영역은 **미검증**으로 명시
